01

Übersicht

POS Count ist eine einfache Demo zur Produktzählung. Sie besitzt zwei unabhängige Zähler: Produkt A und Produkt B. Beide Zählerstände werden auf dem LCD angezeigt.

Hinweis

Der interaktive Zähler ist eine Browser-Demo. Er benötigt keine Datenbank und kann direkt ausprobiert werden.

02

Bedienung

Öffne die interaktive Demo und drücke einen der beiden gelben Knöpfe.

  • Produkt A: erhöht ausschließlich den Zähler von Produkt A.
  • Produkt B: erhöht ausschließlich den Zähler von Produkt B.
  • Zähler zurücksetzen: setzt beide Zähler nach einer Bestätigung auf null.
03

Speicherung der Zählerstände

Die Produktzähler verwenden den lokalen Browser-Speicher (localStorage). Die Zählerstände bleiben damit normalerweise auch nach dem Neuladen der Seite erhalten.

Die gespeicherten Werte sind an den jeweiligen Browser und die Website gebunden. Sie werden nicht automatisch mit anderen Besuchern oder Geräten synchronisiert.

Für eine gemeinsame, geräteübergreifende Produktzählung wäre ein zusätzlicher Server oder eine Datenbank erforderlich.

04

Webseite anpassen

Das Erscheinungsbild wird über assets/css/style.css gesteuert. Die Navigation wird zentral in assets/js/site.js definiert.

Um einen neuen Menüpunkt hinzuzufügen, ergänze das Array NAV_LINKS in dieser Datei um einen weiteren Eintrag. 

{
  label: "Neue Seite",
  href: "./neue-seite.html",
  pages: ["neue-seite.html"]
}

Anschließend muss die entsprechende HTML-Datei im Repository angelegt werden.

05

GitHub Pages

Lege die Dateien in einem GitHub-Repository ab. Achte darauf, dass die Datei index.html im veröffentlichten Verzeichnis liegt.

  1. Öffne die Repository-Einstellungen auf GitHub.
  2. Wähle im Menü den Bereich Pages.
  3. Wähle als Quelle den Branch und Ordner mit den Webseiten-Dateien.
  4. Speichere die Einstellungen und rufe die veröffentlichte URL auf.

Der externe Besucherzähler wird über Besucherzähler-Kostenlos.de eingebunden. Seine zentrale Konfiguration befindet sich in assets/js/visitor-counter.js.
